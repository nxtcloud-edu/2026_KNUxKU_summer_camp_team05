# ADR-0004: Survey v4와 프로필 경계

- 상태: Accepted (MVP)
- 결정일: 2026-08-14

## 결정

MVP Survey v4는 **고정 취향 질문 11개**만 사용한다. 적응형 질문 0~2개 중 MVP 값은 0이며 질문 교체 로직을 구현하지 않는다.

다음은 취향 문항과 분리된 필수 입력이다.

- 가용 날짜와 3박 조건
- 알레르기·접근성·금연 등 하드 제약
- 개인별 목표 예산과 절대상한
- 성인 3명 수용과 객실 분리 동의 권한
- 가치 정책과 사용자 승인 필요 항목

`purposeItems`는 최대 2개의 이번 여행 `ProtectedObjective`로 투영한다. 하드 제약이나 장기 성향으로 자동 승격하지 않는다. 자유서술에서 만든 `ProfilePatchCandidate`도 이번 세션의 확인 화면까지만 사용한다.

## 저장과 노출

- MVP 기본값은 session-only이며 장기 `CanonicalProfile` 저장을 하지 않는다.
- 각 Proxy에는 자기 프로필의 최소 투영만 보낸다.
- `unknown`, `avoid`, `hard`, `approval_required`를 서로 변환하지 않는다.
- 사용자 확인 없는 추론을 확정 프로필 사실로 기록하지 않는다.

장기 프로필 저장은 별도 동의·보존·삭제 설계가 승인된 뒤에만 활성화한다.
