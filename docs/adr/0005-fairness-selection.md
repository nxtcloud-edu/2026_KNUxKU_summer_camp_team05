# ADR-0005: 공정성 및 선택 규칙

- 상태: Accepted (MVP)
- 결정일: 2026-08-14

## 결정

공정성은 말의 설득력이나 모델의 직관이 아니라 동일 입력과 결정론적 계산으로 집행한다.

1. 하드 제약과 필수 Evidence가 통과한 후보만 남긴다.
2. 모든 Proxy는 같은 `proposalSetVersion`에 정확히 한 표를 낸다.
3. 각 Proposal의 0~10000 basis point 만족도를 낮은 순서로 정렬하고 벡터 전체에 leximin을 적용한다.
4. 동률은 평균 만족도, 양보 불균형, 총비용, 이동 부담, 취소 가능성, 근거 품질, 안정된 proposal ID 순으로 푼다.
5. Arbiter는 계산된 선택을 바꾸지 않고 이유와 갈등을 설명한다.

다음 중 하나면 자동 확정하지 않고 `NEEDS_USER_CHOICE`로 보낸다.

- 최저 개인 만족도 5000bp 미만
- 최고·최저 만족도 차이 2500bp 초과
- `ProtectedObjective`의 변경 또는 포기가 필요함
- 객실 분리 등 사용자 승인 항목이 남음

대표 후보가 없거나 중요한 취향 축이 누락된 경우에만 `CandidateGapRequest`로 추가 탐색을 최대 1회 허용한다. 새 ProposalSet이 생기면 이전 Ballot을 폐기하지 않고 무효 표시한 뒤 전원이 다시 제출한다. 서로 다른 버전의 Ballot은 섞지 않는다.

MVP에서는 무제한 자동 재토론, 양보 크레딧, 연속 꼴찌 보정, 중앙 플래너 비교를 사용하지 않는다. Proxy 토론 반복은 최대 3회, 구조화 출력 복구는 최대 1회다.

## 감사 가능성

결과에는 입력 버전, 유효 후보, 탈락 이유, 투표 벡터, 동률 해소 단계, 선택 ID를 남긴다. 모델 성격, 발화 길이, 발화 순서는 점수에 쓰지 않는다.
